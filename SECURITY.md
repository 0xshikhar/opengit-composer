# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue in OpenGit Composer, please do not disclose it publicly in an open GitHub issue.

Instead, please report security vulnerabilities via:
1. **GitHub Security Advisory**:
   - Navigate to the [Security tab](https://github.com/0xshikhar/opengit-composer/security) of the repository.
   - Click **"Report a vulnerability"** to submit a private draft to the maintainers.

2. **Direct Contact**:
   - Email: `security@sika.xyz` or `shikhar@sika.xyz`
   - Include clear reproduction steps and impact details.

We will acknowledge receipt within 48 hours and work with you on a timeline for disclosure and remediation.
